## 说明

- 2025 年的作业已经转向「生成式 AI」：RAG、AI Agent、Transformer、RLHF、Model Editing、Model Merging、Diffusion
- 2026 年的作业继续沿这条线，增加了 Test-Time Scaling、Flow Matching
- 与 2021 年的传统 ML 作业（回归、CNN、Self-Attention）相比，重点完全不同，详见 [ML2021-Spring](https://github.com/jodi345/ML2021-Spring) 仓库里的作业记录
